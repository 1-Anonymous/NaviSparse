# NaviSparse

NaviSparse: Multilevel Navigation Information Fusion for Sparse End-to-End Autonomous Driving

This repository contains the official implementation of the paper "NaviSparse: Multilevel Navigation Information Fusion for Sparse End-to-End Autonomous Driving". Code, examples, and instructions will be added and updated in this repository.
